
# EcoSmart

Sistema inteligente de monitoramento de energia solar para escolas públicas.

## Problema
Escolas públicas possuem alto consumo de energia elétrica e pouco monitoramento energético.

## Solução
O EcoSmart utiliza energia solar, sensores e Arduino para monitorar geração e consumo de energia em tempo real.

## Tecnologias Utilizadas
- Arduino
- Sensores
- Energia Solar
- HTML/CSS/JavaScript
- GitHub

## Funcionalidades
- Monitoramento energético
- Exibição de consumo
- Cálculo de economia
- Sustentabilidade escolar
